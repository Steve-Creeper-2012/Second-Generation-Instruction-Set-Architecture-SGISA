# SGISA_Base_Architecture v1.0.0

## 1.SGISA指令集理念<br>
** SGISA以弥补历史ISA遗留问题与统一ISA为核心，从硬件底层实现架构性整改，避免冗余软件栈和驱动以及无意义的性能损耗，达到更高的算力利用和异构协同算力。**

## 2.SGISA Base Structure

### 指令格式<br>
统一为32位定长指令，一套指令集涵盖所有CPU/GPU/NPU指令，指令集设计于硬件设计深度绑定

## 3.核心重点设计<br>

### 同级异构体<br>
各个异构模块为同等级别，不需要由CPU主导，去中心化

### 统一寄存器架构<br>
#### CPU寄存器<br>
统一64位，浮点用IEEE 754 双精度，FP32, FP16, FP8, INT32, INT16, INT8, INT4等用子字并行，全部补码有符号，浮点与整数分离

### 内存模型<br>
#### 双内存模型共存架构<br>
参考Apple M1的设计，同时设计两套内存模型，即TSO强序内存模型与Weak弱序内存模型共存<br>
该设计有助于兼容arm（Weak弱序内存模型）与x86（强序内存模型），尽可能的降低兼容损耗<br>
通过虚拟内存分区支持细粒度的特定内存块使用特定内存模型，而内存分配与内存模型设定由128-bit系统指令处理

#### 原生TSO/Weak模型支持<br>
NIS指令的默认内存模型为Weak弱序，但也可以设置为TSO强序以应对特定环境下的需求<br>
arm转译则强制Weak，x86转译强制TSO
