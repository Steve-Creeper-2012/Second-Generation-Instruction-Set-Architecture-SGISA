# 上下文切换与进程迁移设计

## 1. 硬件模块

| 模块 | 功能 | 属性 |
|------|------|------|
| IMU | 中断管理单元 | 接收/分发中断，查PIT |
| CIDU | 中央中断分配器 | 管理核心的一部分，路由中断到LIP |
| LIP | 本地中断处理器 | 每核一个，接收CIDU中断，存储迁移信息 |
| CC | 上下文缓存 | 每核私有，容量可配置，自动LRU+LFU，强制32位PID |
| CCB | 上下文缓存缓冲区 | CC预留1 entry，用于NoC接收或overflow缓冲 |
| PIT | 进程信息表 | 内存中，分核心PIT+全局PIT，IMU只读 |
| PCMT | 进程核心映射表 | 内存中，OS写，系统态/内核态可读写 |

## 2. 内存模型设置指令

| 指令 | 操作数 | 功能 |
|------|--------|------|
| `MMSET imm1` | 1bit立即数 | 设置当前核心内存模型（Weak/TSO），排空流水线 |

## 3. 上下文切换指令

| 指令 | 操作数 | 功能 | 延迟 |
|------|--------|------|------|
| `CTXTSAVE` | 无 | 保存当前进程全部上下文到CC，标量1-3c退休，向量异步 | 标量1-3c，向量10-15c |
| `CTXTRECOV Rs` | Rs=PID | 从CC/内存恢复指定PID上下文，成功后删除源数据 | CC命中1-3c，内存200-500ns |
| `CCCTXTFLU Rs` | Rs=PID | 广播到所有核心，删除CC中该PID entry，N周期ACK超时 | 数十~数百周期 |
| `PROCMOVINT Rs1, Rs2, Rd` | Rs1=CID, Rs2=PID, Rd=目标核心 | 触发进程迁移中断 | 异步 |
| `CTXTSEND Rs, Rd` | Rs=PID, Rd=目标核心 | 通过NoC直接发送上下文到目标核心，修改PCMT | NoC延迟60-80c |

## 4. 上下文切换机制

| 机制 | 说明 |
|------|------|
| 脏标识 | 标量单元1bit + 向量单元1bit，CTXTSAVE/CTXTRECOV时跳过未修改部分 |
| 双内部指令 | CTXTSAVE/CTXTRECOV解码拆为标量uop+向量uop，标量uop退休后OoO继续 |
| 移动语义 | CTXTRECOV成功后删除CC/内存源数据，下次需重新CTXTSAVE |
| ISR | 无上下文中断服务例程，使用影子寄存器，从头执行，PID/入口/MPMTR由内核启动配置 |
| NoC直接发送 | CTXTSEND通过NoC发送1.3KB上下文到目标核CC |
| CC满处理 | NoC到达时CC满 → 写入CCB，同时触发最早entry fallback到内存 |
| 中断挂起 | 迁移过程中IMU挂起发给MIGRATING进程的中断，迁移完成后重定向 |
