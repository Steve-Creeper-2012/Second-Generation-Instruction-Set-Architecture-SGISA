# NIS_ISA_CPU v0.0.1
## Preamble
NIS是混合定长指令集，共分为16-bit/24-bit/32-bit/48-bit长度指令*，采用逻辑运算（CPU）与并行运算（GPU/NPU）统一指令集的方案，实现零消耗调度。<br/>
*注：以下16位长指令称为"V指令"，24位为"F指令"，32位为"P指令"，48位为"S指令"，详情请参考NIS_Base_Architecture*

## 寄存器分配
NIS硬件采用可调节同构线程化执行模型，每个CPU线程都拥有32个统一64-bit位宽的物理寄存器，但是不同指令可操作的寄存器数量却不同。<br/>
除掉头部的三位标识符，V指令的存载荷为13-bit，F指令为21-bit，P指令为28-bit，S指令为45-bit<br/>
